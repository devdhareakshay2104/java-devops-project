# Java DevOps Project:

## Java Maven Application Automated CI/CD Deployment on AWS using Jenkins and Ansible:

This project demonstrates the development, build, testing, and planned automated deployment of a Java Maven application using DevOps tools and AWS.

The project is being developed step-by-step to understand the complete CI/CD workflow using Git, GitHub, Maven, Jenkins, Ansible, Docker, and Kubernetes.

---

## Project Objective

The main objective of this project is to automate the process of:

1. Managing Java source code using Git and GitHub.
2. Building the Java application using Maven.
3. Running automated unit tests.
4. Creating a JAR application artifact.
5. Automating the CI/CD process using Jenkins.
6. Deploying the application using Ansible.
7. Hosting the application on AWS EC2.
8. Containerizing the application using Docker.
9. Deploying the containerized application using Kubernetes.
